# E-commerce Customer Churn Analysis

## Project Overview

This project explores customer churn in an e-commerce business using SQL analysis and a dashboard to identify customer characteristics and behaviours associated with churn.

## Objectives

- Calculate the overall customer churn rate.
- Investigate churn across customer tenure, payment preferences, and login devices.
- Explore the relationship between complaints, satisfaction, and customer retention.
- Present findings through a visual dashboard.

## Tools Used

- SQL for data cleaning, exploration, and business analysis.
- CSV for the source dataset.
- Dashboard visualization for communicating findings.

## Repository Structure

- `data/`: Source customer dataset.
- `sql/`: SQL queries for cleaning and analysing the data.
- `dashboard_overview/`: Dashboard screenshot.

## Dataset

The dataset contains customer-level attributes, including churn status, tenure, preferred payment mode, login device, satisfaction score, complaints, and order behaviour.

## Key Questions

1. What proportion of customers churned?
2. Which customer groups show higher churn rates?
3. How are tenure, complaints, and satisfaction associated with churn?
4. Which findings could inform customer-retention strategies?

## How to Explore

1. Review the CSV file to understand the available variables.
2. Open the SQL file to inspect the analysis queries.
3. View the dashboard to explore the visual presentation of the findings.

## Limitations

Observed associations do not establish causation. Any proposed retention actions should be validated with further analysis or experiments.
